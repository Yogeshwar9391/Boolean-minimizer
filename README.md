
# Boolean Logic Minimizer

A Python-based Boolean Logic Minimizer
using the Quine-McCluskey algorithm.

## Features
- Supports 2 to 10 variables
- Minterm input
- Don't-care conditions
- SOP expression input
- Prime implicant chart
- Essential prime implicants
- Step-by-step grouping
- Tkinter graphical interface

## Requirements
- Python 3
- Tkinter

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run:

   python dcdproject.py

## Technology Used
- Python
- Tkinter
- Quine-McCluskey Algorithm
